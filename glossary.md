# Glossary - Hachiemon

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: kept, hyphenated (Hachiemon-san). Name order: Western.
- Romanisation source: official English names, else an earlier fan patch (none found), else Hepburn without macrons.
- Credits: English.
- Register / flavour: casual comedy. Hachiemon and most of the cast speak Kansai dialect; render it as loose, friendly informal English, never as phonetic eye dialect. Sound effects: *Slam!*
- Abbreviations: full names and terms everywhere, prefer engine changes over shortening.

## Style rules
- Punctuation map: 「」 -> "...", ！？ -> !?, － runs -> --, 〜 stretching a word -> repeat or drop it, ♥ stays (font has it).
- Jokes and wordplay keep their punch even if the literal meaning shifts. Lips (くちびる) are the running joke: keep them central.
